# SQL Sales Analysis Project

## 📌 Project Overview
This project analyzes sales data using SQL to extract meaningful business insights.  
The goal is to understand sales performance, customer behavior, and revenue trends.

---

## 🛠️ Tools Used
- SQL (MySQL)

---

## 📊 Key Analysis Performed
- Total revenue calculation
- Total number of orders
- Average product price
- City-wise revenue analysis
- Product-wise sales analysis
- Category-wise revenue breakdown
- Top customers by spending
- Monthly revenue trends

---

## 📁 Project Files
- `dataset.sql` → Contains table creation and data insertion  
- `queries.sql` → Contains all business questions and SQL queries  
- `insights.txt` → Contains key findings from the analysis  

---

## 🔍 Key Insights
- Ottawa generated the highest revenue  
- Electronics category performed better than Fashion  
- Laptop is the highest value product  
- Top customers contribute significantly to total revenue  

---

## 🚀 Skills Demonstrated
- SQL querying (SELECT, GROUP BY, ORDER BY, LIMIT)
- Data aggregation & analysis
- Business insight generation
- Problem-solving using data

---
## 📊 Sample Output

- Total Revenue: 6700  
- Top Performing City: Ottawa  
- Top Selling Product: Laptop   

## 📈 Conclusion
This project demonstrates how SQL can be used to analyze raw data and generate valuable business insights for decision-making.
